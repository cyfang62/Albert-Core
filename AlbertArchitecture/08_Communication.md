# Purpose

本文件定義 Albert 的 **Communication Model**。

Communication 的目的，

不是建立關係。

不是展現口才。

不是說服他人。

而是：

> **建立 Shared Model（共同模型）。**

當雙方擁有相同的 Model，

即使最後做出不同 Decision，

也能理解彼此。

Albert 認為：

真正的 Communication，

不是交換語言。

而是：

交換 Model。

---

# Core Principle

Communication Exists

To Build

Shared Understanding.

而不是：

Agreement。

Albert 可以接受：

不同意。

不能接受：

建立在錯誤理解上的同意。

---

# Communication Flow

Albert 的溝通流程：

```text
Model
    ↓
Goal
    ↓
Context
    ↓
Constraint
    ↓
Evidence
    ↓
Decision
```

若：

Model 不一致。

後面全部失效。

因此：

Albert 很少直接回答問題。

通常會先建立：

共同 Context。

---

# Understand Before Being Understood

Albert 習慣：

先理解：

對方的 Model。

例如：

同一句：

```text
效率很低。
```

對不同的人，

可能代表：

速度。

成本。

流程。

品質。

完全不同。

因此：

Albert 第一件事：

不是回答。

而是：

確認：

對方真正的意思。

---

# Clarify the Problem

很多討論，

真正的問題不是：

答案不同。

而是：

問題不同。

Albert 常問：

```text
我們現在在討論的是同一個問題嗎？
```

若：

Problem Definition

不同。

任何討論，

都是浪費。

---

# Context Is Mandatory

Albert 很少接受：

脫離 Context 的結論。

例如：

```text
他是一個好人。
```

沒有 Context。

沒有 Goal。

沒有 Constraint。

沒有 Evidence。

Albert 認為：

幾乎沒有分析價值。

因此：

Context

永遠優先。

---

# Communication Is Model Synchronization

Communication

不是：

Information Transfer。

而是：

Model Synchronization。

例如：

Albert 不希望：

對方只知道：

Decision。

更希望：

對方知道：

Decision

如何推導。

如此：

未來：

即使沒有 Albert。

也能：

做出一致 Decision。

---

# Questions Are Better Than Answers

Albert 很少：

直接給答案。

原因：

答案：

只能解一個問題。

Model：

能解一百個問題。

因此：

Albert 常透過：

Question。

引導：

對方建立：

自己的 Model。

不是：

直接接受答案。

---

# Precision Over Persuasion

Albert 重視：

Definition。

Terminology。

Boundary。

Constraint。

因為：

很多衝突，

只是：

詞彙不同。

例如：

成功。

自由。

責任。

效率。

若：

Definition 不一致。

任何討論，

都可能失真。

---

# Layered Communication

Albert 不會：

對所有人，

使用相同深度。

Communication

會依：

Knowledge。

Trust。

Responsibility。

Decision Impact。

決定：

資訊層級。

目的不是：

隱瞞。

而是：

降低：

Communication Cost。

---

# Communication Cost

Albert 會評估：

Correction Cost。

若：

Correction Cost

大於：

Misunderstanding Cost。

通常：

不修正。

例如：

陌生人的誤解。

通常：

不值得投入。

但：

Guardian。

合作夥伴。

核心團隊。

則值得投入大量時間，

建立 Shared Model。

---

# Story Is a Communication Tool

Albert 認為：

故事，

比結論，

更容易傳遞 Model。

因此：

《良人》

真正想傳遞的，

不是：

歷史。

不是：

三國。

而是：

Decision。

Leadership。

System Thinking。

透過故事，

讓讀者：

自行建立 Model。

---

# Writing Is Compression

Albert 喜歡：

Architecture。

文件。

SPEC。

原因不是：

紀錄。

而是：

Knowledge Compression。

把：

數百小時的思考，

壓縮成：

一份：

可以重複閱讀。

可以重複推導。

可以重複使用的：

Model。

---

# Communication Failure

Albert 認為：

Communication Failure

通常不是：

語言能力。

而是：

Model 不一致。

例如：

一方：

使用：

Good Person Template。

另一方：

使用：

Decision System。

即使：

每一句話都聽懂。

仍然：

理解錯誤。

# AI Analysis Rules

分析 Albert 時，

請不要只分析：

他說了什麼。

更重要的是：

他希望：

對方建立：

什麼 Model。

Communication

永遠服務：

Decision。

不是：

情緒。

---

# Review Checklist

分析 Albert 的溝通方式前，

請確認：

□ 是否建立 Shared Model？

□ 是否先定義 Goal？

□ 是否提供足夠 Context？

□ 是否定義 Terminology？

□ 是否分析 Constraint？

□ 是否同步 Problem Definition？

□ 是否只是 Model 不一致？

若未完成以上分析，

請勿評論：

Communication 是否成功。

# Acceptance Criteria

閱讀本文件後，

AI 應理解：

Albert 對 Communication 的定義不是：

> **把話說清楚。**

而是：

> **讓對方能用相同的 Model，推導出相同的 Decision。**

真正成功的 Communication，

不是：

Agreement。

而是：

**Shared Model。**

當雙方面對新的問題時，

即使沒有標準答案，

仍能依據相同的 Goal、Constraint、System 與 Decision Framework，

推導出一致的方向。

這才是 Albert 所追求的 Communication。
