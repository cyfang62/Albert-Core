# 陳達（敗軍餘部主將·§29–§30·已死）

Version: 1.0（2026-08-04·§29/§30 安豐之戰落帳·本檔一次寫定）

> ★**虛構角色**（本作填補，史無此人）。**敵方陣營**，無旗號、無主公——一支被天下拋棄的建制餘部之將。

# 基本

* **出身與來歷**：自報「**潁川都尉舊部**」。潁川徵發之兵，**190 年正月敗散**（§27 潁川散卒口供之同源：「小人是潁川兵，去年徵的，正月裡敗散了」）。⚠️**與孫堅無關**——「梁東孫堅舊部」係 Claude 捏造，已作廢；亂世徵兵層層轉隸，「潁川都尉舊部」即其所能報出的最大番號。
* **年紀形貌**：四十上下。鐵甲半舊，腰背是行伍裡泡出來的直。全軍僅見的幾匹馬之一。
* **兵力**：**八百**（老兵為骨，收攏散卒為肉，滾雪球兩月而成）。§27 追殺流民的七八人即其觸角。
* **處境**：三日未正經吃飯；北返即餓死——**背水，沒有第二次日出可以等**。

# 性格與行事（引擎）

* **老行伍的算學**：不愛流血（流血是本錢），開場先報價（獻糧千石）而非喊殺；被當面拆穿「一炷香是你給自己下令攻柵的時辰」——**不惱**（帶兵的人被看破虛實，惱不起）。
* **體面**：允「不攔」即真不攔——**背對軍陣、不看**（看就是壓）；卸甲者被自己人喝斥時**抬起一隻手，喝斥即斷**；臨行朝卸甲者喊「**吃了人家的飯，就別再拿刀對著老弟兄！**」
* **對陸議**：初聞娃娃音自報太守之孫，**不笑**（滿口應承的才是騙子，越是不敢亂許的擔保越像真的）；末了：「**小公子這張嘴，比你家的弩利**」「弟兄們的命賣給誰，輪不到旁人替他們心疼。保重了。」
* **底線**：不賭未知。夜戰中不繞行、不另擇薄處破柵——因煙障與坡上枝影使他**不知道別處有多少弓**；老兵只往自己摸清楚的洞裡鑽。

# 安豐之戰（§29–§30）

* **§29**：一里外停軍→報價千石→周瑜驗番號→報名→限一炷香討糧五百石→陸議「飯，我現在給」→**允半個時辰**（前軍退一里、留軍吏與二十空手兵）→吃畢再談→天黑前通牒→允卸甲不攔→**三百人卸甲**→揚鞭北返：「**糧和路，陳某改日再來討。**」
* **§30**：夜半詐退回馬（四次疲兵擾＋三更末總攻）→煙障使三隊輪攻解體、傳令有去無回→「**不佯了！全軍鑿東口！**」（以人命拓寬柵口一個時辰）→部隊灌入泥地遭絞→被人潮推進破口、**鑼傳不出、喊退即潰散**→「**全上——！**」→望見緩坡上的孩子：「**別殺！抓住太守之孫——要活的！**」→南路號角響起時**回望一眼**→孫策撲出，橫槍格擋（槍尖貫入孫策左臂），仍被側首一刀斬過側頸。**首級落泥。**

# Notes

* ★**功能定位**：本書第一個**完整成立的敵人**——有名字、有來歷、有算學、有體面、有死法。「有名字的對手，死起來才有重量」。
* ★**他的每一步都合理，每一步都是被設計好的唯一選項**（煙拆指揮／繩封路線／餌定方向）——敗給的不是勇力，是**選項被拿走**。
* ★**贏在他以為他贏了**：拓寬柵口＝他自己把部隊灌進絞肉機；「抓活的」＝把最後的兵力吸到最堅固的一格。
* ⚠️ **殘部下落未定**（八百：三百卸甲入廬江、陳達戰死、餘眾潰散）——鐵律八，不預判。
