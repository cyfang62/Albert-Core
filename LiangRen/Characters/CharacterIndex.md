# Purpose

本文件為《良人》的角色索引。

目的不是取代各角色獨立檔案，

而是提供快速查詢：

* 角色身份
* 所屬勢力
* 首次登場
* 目前狀態
* 與主角關係
* 對劇情的重要性

角色詳細設定請參考各角色 Markdown 檔案。
