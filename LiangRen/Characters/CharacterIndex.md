# Update Note (v2.6)

* 新增**袁術**（字公路，汝南袁氏；史實人物），建 Yuan/YuanShu.md。
  本作反派主軸（廬江之圍推手）。189入夏還在洛陽當虎賁中郎將（宿衛官、尚非軍閥），189秋才逃據**南陽（宛）**當後將軍；

* 新增**周崇**（老吏）、**杜衡**（年輕書佐）＝陸康的眼睛（§2撥給、§3查損耗、§4據實答/日報揭曉），

# Family Tree (確認版)

```text
陸紆（陸議祖父，字叔盤，城門校尉，已逝）
   │（兄）
陸康（從祖父，字季寧，廬江太守、陸氏族長／大當家，126–195）
   
陸紆 ─ 子 ─ 陸駿（陸議父，九江都尉，已逝）
                 │
            陸議／陸遜（字伯言，主角，生 183）

生母（原陸夫人，已逝） ── 姊妹 ── 姨母（撫養陸議）

旁支：陸暐（字子明，與陸駿同輩，陸議族叔；虛構）
```

* 陸康 = 陸議從祖父，亦為陸氏族長／大當家
* 陸駿 = 陸議父，亦為陸康之姪
* 陸暐 = 陸氏旁支，與陸駿同輩，陸議之族叔（虛構）
* 姨母 = 生母之姊妹，生母已逝後撫養陸議

家系依《陸氏世頌》（裴松之注）／《後漢書》確認；陸暐為虛構旁支，不入史實家系。
