# Current Status

* §3〈量〉：與周崇隨陸議查三縣損耗（老少搭配中的「少」）。**先服**（比周崇早）——霉耗那段被「還要試？」震到，「說不上哪裡不對，只覺得這法子……穩得有點嚇人」；日後成**傳話的嘴**（★自然溢出、非陸議刻意收服）。
* §4〈開門〉揭曉：**陸康早經杜衡的「日報」把陸議這一季的作為聽了一整季**（只看不問＝早懂）——
  杜衡＝陸康安在陸議身邊、按日回報的眼睛。
* **§11–§12（189年八月·河道關津）**：★**續任陸議出行班底**（霍篤／周崇／杜衡／郡兵二人），管**記錄**。
  - ★**日報線持續運轉**：「**每一日，都有人把他的行蹤，一字不落地報到郡府**——小主子今日練了武、去了渡口、在江邊站了半晌、看得出神。」→ 這正是 §12 陸康那句「**你這一個月天天往江邊跑，祖父都知道**」的資訊來源。
  - ★與霍篤（武職眼線）分工：杜衡＝文職日報、霍篤＝武職貼身。
