# Basic Information

* 姓名：秦平。行內稱**秦掌櫃**。
* 年齡：五十來歲。商旅打扮，禮數周全，話不多繞。
* 出身：**北路行商，亂起後南來定居舒縣**——故南北兩路皆有人脈（襄陽細節、南陽風聲皆撈得到）。
* 身分：關津那間屋子的掌櫃。⚠️**屋子與人皆非陸議所有**（陸議語：「我只是添了些柴，讓那兒多一雙耳朵」）——錢是陸議的，規矩是陸議立的，鋪面經營自主。

# ★ 報信規矩（行為鐵則·陸議所立）

* **能互相對上的，才送進來；對不上的，照原話說不知道。**
* 只報「聽見了什麼」，**不加判斷**（判斷是陸議的職分——§25 陸議情報倫理：「掌櫃報聽見的，我報我看出的」）。
* 不敢說死的（時日、確數）明言不敢說死。
* 專項囑託（§24 起）：凡有孫將軍（孫堅）的消息，不論大小，先送府裡。
