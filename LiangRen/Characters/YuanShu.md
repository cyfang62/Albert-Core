# Basic Information

* 姓名：袁術，字公路。
* 出身：汝南袁氏（四世三公之家），袁紹從弟（一說異母弟）。
* 生卒：？–199（建安四年嘔血而死）。
* 189入夏身分：**虎賁中郎將**（何進部下、宿衛洛陽京城），**尚非軍閥、無地盤**。
  ★189秋（189年9月董卓廢帝立獻帝後）任後將軍，因怕董卓加害而逃出洛陽、南奔**南陽一帶**——★但南陽此時仍是南陽太守張咨的地盤，袁術**尚未據有**，只是逃亡投奔、挂名後將軍、無實地盤。**★真正據有南陽郡＝190年（初平元年）孫堅北上殺南陽太守張咨後，袁術才接替支配南陽、收孫堅為部下**——「軍閥袁術」與其南陽基地實成於190年，非189秋。〔史料：《三國志》呉志孫破虜討逆傳；孫堅殺荊州刺史王叡、南陽太守張咨後袁術方據南陽。2026-07核准更正。〕

# Current Status（189入夏·故事現在）

* 人在**洛陽**，任虎賁中郎將、宿衛京城，是何進部下。董卓未入京、天下未亂，他**還不是軍閥、無地盤**。
* **對廬江威脅≈0（休眠）**。與陸康尚無任何交道（「拒袁術」是194索米事件，此時未發生）。
* ★軌跡預告：189秋董卓廢帝→袁術任後將軍、逃奔南陽一帶（★尚未據南陽·南陽仍張咨的）→190討董、孫堅北上殺張咨→袁術才據南陽、孫堅來投為先鋒。此刻這些皆未發生。

# Timeline（史實·V型軌跡）

* 189入夏：虎賁中郎將、在洛陽（宿衛官），尚非軍閥。
* 189秋：董卓廢帝後任後將軍、逃奔南陽一帶（★尚未據有·南陽仍張咨的）。**190（初平元年）：關東討董起、孫堅北上殺南陽太守張咨→袁術才據南陽郡、收孫堅為先鋒**；孫堅191破洛陽得玉璽。＝巔峰。
* 約192：孫堅攻劉表戰死，失頭號戰將。
* 193：劉表斷糧道→匡亭大敗於曹操→狼狽東逃→殺揚州刺史陳溫、據淮南壽春（成廬江鄰居）。＝谷底。
* 約194：得孫策（孫堅舊部來投·回血）；索米三萬斛於陸康被拒→遣孫策攻廬江。
* 194-196：圍廬江，史實城陷、陸康病逝。
* 195-197：淮南蝗災大旱、民相食、自崩；197稱帝、199嘔血死。

# Relationship（與主角／陸康）

* 與陸康：194向陸康索米三萬斛（為打徐州），陸康拒→遣孫策攻廬江→陸康城破病逝、陸氏宗族死近半。
  ＝**滅陸康、重創陸氏的關鍵勢力**，故為陸議「改命靶心（廬江之圍）」的主要對手。
* 與陸議：陸議之父陸駿昔任九江都尉（治壽春）——父親舊任之地，成日後滅族仇敵之巢穴（伏筆）。

# Personality / Decision Style

* 出身頂級門第、驕奢、征斂無度、不治法度、貪求無度（索米給了沒完，故陸康看穿而拒）。
* 決策短視、四戰之地（南陽）不能守，敗多於謀；靠一連串失敗才偶然逼近廬江。

# Ability（本作定位）

* **下行、自崩、且靠失敗落腳的對手，非膨脹的巨人。** 絕對實力V型（189峰→193谷→194回血）；
  對廬江威脅：189≈0→193據淮南始現→194得孫策拉滿。
* 致命弱點：糧／民心（淮南貧、他不善治，195後天災民相食＝史實寫死的自崩）。
