# 基本

* 郡治：**舒縣**（周瑜老家；孫策將來居地與私仇地）。
* 歸屬：揚州（州治壽春，揚州刺史陳溫）；太守**陸康**（62歲·務實正直漢官）。
* 定位：本作主場、陸議佈局改命之地；廬江之圍（約194–196）為第二章主線。

# 糧速率／續航（接 CombatSystem 二、四）

* **對決預估值**：糧食起點3000；§3損耗改造事件把月存糧速率鎖 60→90/月 → 對決終點≈**4200（+40%）**。之後只在事件（漏糧侵蝕/毀倉/再優化）時才動。
* **續航**：年耗糧＝守軍1500＋人口1000×0.6＝**2100**；續航＝4200÷2100＝**2.0年**（與守城時間 T≈2年對齊）。
* 陸議 §3減損耗、§5拓墾＝同時拉高糧食終點、壓低年耗糧，把續航往外推。

# 人口（史實地基·已查證·附算式）

* 廬江郡永和五年（140年）：**戶101392／口424683**（續漢書郡國志·逐字驗證）。
* 自然下降率：由全國140年口47,892,413→三國263年約767萬（魏443＋蜀94＋吳230萬），跨123年年均複合≈-1.48%/年；廬江在陸康治下相對安定，取**-1%/年**為工作值。
* **減病令（§6落地）**：把死亡數壓下，自然斜率由 -1%/年 扭成 **+1%/年**（掛事件、對決終點往上搬）。廬江由此逆漢末人口大勢、成亂世中罕見「人口進血」之地。
* 真正大頭在**難民**：193–194徐州被曹操屠碎的大浪（見 LuJiang_PowerMeter 三·六），會大幅抬高對決期人口/丁壯/拓墾勞力——惟收難民→年耗糧↑，須與糧食續航一併算（雙面刃）。

# 地理鄰接（影響外交/難民/威脅方向）

* 北/西：九江郡（州治壽春所在，見 Commanderies/JiuJiang.md）——189入夏太守服虔、州刺史陳溫駐此；193後被袁術吞併成敵巢。
* 徐州方向：193–194曹操屠徐州→難民南下推力（生路磁石戰略）。
* 荊州劉表：外交牽制主力線（削袁術圍城持續力）。
