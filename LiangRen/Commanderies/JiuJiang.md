# 基本

* 郡治/州治：**壽春**（揚州州治所在；日後袁術之巢）。
* 189入夏太守：**服虔**（經學大儒）；190起：**劉邈**（漢室宗親·空降）。
* 揚州刺史：**陳溫**（駐壽春，州級疊在本郡之上）。
* 定位：**看得到、用不到**（隸屬不同、各守其土，陳溫還反向抽廬江兵）；193後被袁術吞併＝袁術據淮南的 feedstock。

# 守將輪替與州級加成

* **守將**：189＝服虔（守30·經學文弱）；190＝劉邈（守33·宗室空降無班底）。守將弱＝這郡「守城時間」偏低（防禦4000＋民心4000＋弱守將→撐不久）。
* **州級加成·陳溫**（揚州刺史）：可跨郡調兵→兵力可短期上調一段（documented 一次調數千：撥曹洪2000廬江精兵、與周昕合給曹操4000+）；但兵易被大義/關係抽走、不穩。個人守37。
* ★一個九江郡盤＋守將輪替＋州級加成＝解掉舊「刺史與太守勿相加/重疊」的麻煩。

# 兩條機制連動

1. **可為廬江所用＝0（現況）**：隸屬不同、各守其土；陳溫還反向抽廬江兵。列「潛在變數」＝條件達成才可借力（借力須過質詢關＋蝴蝶效應，不免費、本身即風險）。可借力窗口＝**189–192**。
2. **它＝袁術的 feedstock**：193袁術據壽春，整碗端走此九江郡盤（袁術「據淮南跳升」的立足本錢正是這塊，見 LuJiang_PowerMeter 三·五B）。過了189–192窗口，這份鄰居實力就從「或可借」變成「敵人的血肉」。
