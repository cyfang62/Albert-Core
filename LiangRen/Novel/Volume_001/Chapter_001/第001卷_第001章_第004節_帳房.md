《良人》

第一卷 江東初醒
第一章 立足
第四節 帳房

族老離開後的第二日。
陸議第一次主動離開了院子。
目的地是帳房。
消息很快傳到了帳房裡。
陳管事正在核對租冊。
聽見僕役稟報時，手中的筆微微一頓。
「小公子要看帳？」
旁邊幾名帳房先生也愣了一下。
隨即有人失笑。
「小公子今年才五歲吧？」
「五歲便想學管家了？」
帳房內響起幾聲善意的笑聲。
陳管事也笑了。
「孩子總有好奇的時候。」
說著，隨手從架上取下幾卷近三年的總帳。
「拿去吧。」
「若看不懂，便當故事看看。」
福伯抱起帳冊。
沒有多說什麼。
轉身離去。
陳管事則低下頭，繼續核帳。
這件事很快便被拋到腦後。

一個時辰後。
福伯又來了。
「小公子看完了。」
陳管事抬起頭。
「看完了？」
福伯點頭。
陳管事笑了笑。
「那便再拿幾卷。」
第二批帳冊送了出去。
不到半個時辰。
福伯又出現了。
帳房裡的人終於有些詫異。
「又看完了？」
福伯苦笑。
「又看完了。」
眾人面面相覷。
陳管事卻不以為意。
「孩子新鮮勁重。」
「過兩日便膩了。」
說完又取出幾卷帳冊。
然而事情並沒有如他預料。
帳冊送出去的速度越來越快。
最開始。
陸議需要反覆翻閱。
有些地方甚至要問福伯數次。
可漸漸地。
索取帳冊的間隔越來越短。
帳房先生甚至還沒來得及喝完一盞茶。
僕役便又跑了過來。
「福伯說，小公子還要。」
有人忍不住笑道：
「這是看帳還是吃飯？」
另一人道：
「照這速度，再過幾日，帳房怕是要搬空了。」
眾人都笑了。
唯獨陳管事沒有。
因為他發現了一件奇怪的事。
小公子索要的帳冊開始變了。
起初只是近年的總帳。
後來是租冊。
再後來是庫房簿。
接著是佃戶名冊。
最後甚至開始翻查更久以前的舊帳。
這已經不是孩童的好奇心了。
卻又不像是在查什麼。
更像是在……整理。

傍晚。
陳管事終於忍不住。
親自往內院走了一趟。
院門半掩。
他透過縫隙看去。
不由微微一怔。
院內很安靜。
案上堆滿了竹簡與紙冊。
而陸議正趴在桌前。
左手翻閱帳冊。
右手則拿著一截削細的毛筆。
在粗紙上不停書寫。
紙上畫滿方方正正的格子。
不像字帖。
倒像是棋盤。
每個格子裡都寫著奇怪的符號。
既不像隸書。
也不像篆字。
更不是任何他認識的文字。
其中一張粗紙最上方寫著：
東田租糧
 -------------
│ 年份│ 租糧│
 -------------
│ 183 │ 583 │
│ 184 │ 612 │
│ 185 │ 598 │
│ 186 │ 541 │
 -------------
旁邊另一張則寫著：
東田佃戶
 -------------
│ 年份│戶數│
 -------------
│ 183 │ 182 │
│ 184 │ 177 │
│ 185 │ 169 │
│ 186 │ 161 │
 -------------
而第三張粗紙上。
原本分散在數卷帳冊中的內容。
竟被重新排列到同一張紙上。
東田租糧／佃戶對照
 --------------------
│年份 │租糧 │戶數 │
 --------------------
│ 183 │ 583 │ 182 │
│ 184 │ 612 │ 177 │
│ 185 │ 598 │ 169 │
│ 186 │ 541 │ 161 │
 --------------------
陳管事一個字也看不懂。
可他卻看得出來。
原本散落在十餘卷帳冊中的資料。
如今竟被濃縮在三張紙上。
更詭異的是。
那些數字彼此之間似乎存在某種聯繫。
可他偏偏看不出來。
這種感覺。
就像明明看著一幅棋局。
卻完全不知道對方下一步要落在哪裡。
再加上旁邊還畫著一些奇怪的記號。
○ △ × ？
陳管事更是完全看不懂。
可有一件事他看懂了。
桌上的帳冊被重新分門別類。
田租一堆。
庫房一堆。
佃戶一堆。
人情往來又是一堆。
整整齊齊。
井然有序。
彷彿有一雙看不見的手。
正在把散亂二十年的資料重新拆解、排列、組合。

陸議似乎察覺有人。
抬起頭。
看見陳管事。
微微點頭。
「陳管事。」
陳管事愣了一下。
隨即拱手。
「小公子。」
陸議沒有多說什麼。
只是低下頭。
繼續整理手上的資料。
彷彿眼前站著的不是陸家帳房主管。
而只是一名普通路人。
陳管事站在原地。
沉默片刻。
終究還是問道：
「小公子在做什麼？」
陸議頭也不抬。
「找規律。」
陳管事微微皺眉。
「規律？」
陸議沒有解釋。
因為他忽然發現。
自己竟找不到合適的詞。
在他的世界裡。
這只是再普通不過的資料分析與系統建模罷了。
可在東漢末年。
似乎還沒有人試著從一堆零散的記錄裡。
拼湊出事情原本的模樣。
於是他只說：
「把東西放在該放的位置。」
陳管事聽了後。
就沒有再問。
因為他忽然發現。
自己根本看不懂桌上的那些粗紙。
更看不懂這個五歲的孩子。
離開院子後。
陳管事回到帳房。
本想繼續處理手邊事務。
卻遲遲無法落筆。
案上的帳冊攤開許久。
墨汁甚至在筆尖凝結。
帳房先生見狀，不禁問道：
「管事？」
陳管事回過神。
「嗯？」
「小公子那邊如何？」
眾人都露出好奇神色。
畢竟這幾日。
整個帳房都快被折騰瘋了。
陳管事沉默許久。
最後只說了一句。
「不知道。」
眾人一愣。
「不知道？」
陳管事看向窗外。
腦海裡浮現的。
是那滿桌竹簡。
以及那些看不懂的符號。
最初。
他以為那只是個孩子。
後來。
他也以為那只是孩子的一時興起。
可現在。
他第一次有些拿不準了。
因為他發現。
他做了二十年帳。
看過精明的人，看過貪心的人，看過裝傻的人。
可他從沒見過一個五歲的孩子，
能讓他這個帳房老手，
在自己待了二十年的帳房裡，
覺得冷。

正當此時。
帳房外忽然傳來急促腳步聲。
眾人同時抬頭。
下一刻。
福伯出現在門口。
帳房先生們面面相覷。
忽然有種不祥預感。
果然。
福伯咳了一聲。
有些不好意思地說道：
「小公子說。」
「還要帳。」
帳房內瞬間安靜。
陳管事沉默片刻。
終於放下手中的筆。
第一次親自站起身。
「這次。」
「他要什麼？」
福伯低頭看了一眼手中的紙條。
神情有些古怪。
「二十年前的田契。」
福伯說完。
帳房裡忽然安靜下來。
因為那已經不是帳。
而是陸家的根。
