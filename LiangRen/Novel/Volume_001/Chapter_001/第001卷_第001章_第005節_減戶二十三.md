《良人》

第一卷 江東初醒
第一章 立足
第五節 減戶二十三

二十年前的田契，最後還是送到了陸議面前。
不是全部。
至少不是一開始就全部。
陳管事很謹慎。
他送來的是吳郡各地的田契副冊，旁邊還附了近年的租冊、佃戶名冊與庫房進出簿。
這已經夠了。
陸議並不急著看更多。
資料不是越多越好。
沒有方法，資料越多，只會越亂。

而現在。
他的方法已經建立起來了。
案上鋪著幾張粗紙。
粗紙上畫滿方格。
每張紙左側是年份。
右側則是戶數、租糧、支出與庫存。
有些地方畫著圓圈。
有些地方畫著三角。
有些地方則標著問號。
福伯看不懂。
陳管事看不懂。
帳房先生也看不懂。
可對陸議而言。
那是他的索引。
他的標記。
也是他在這個時代暫時唯一能依靠的工具。
一卷卷帳冊被拆開。
一筆筆數字被重新填進表中。
起初只是東田。
後來是西田。
再後來，是附近幾處莊田。
當那些原本散落在竹簡與紙冊中的記錄，被重新排列到同一張粗紙上時，藏在流水帳裡的東西，終於開始浮出水面。
不是貪墨。
不是假帳。
也不是誰偷偷拿走了糧食。
而是一條不斷往下的線。
陸議看著粗紙上的表格，久久沒有說話。
東田租糧／佃戶對照
│年份 │租糧 │戶數 │
│ 183 │ 583 │ 182 │
│ 184 │ 612 │ 177 │
│ 185 │ 598 │ 169 │
│ 186 │ 541 │ 161 │
西田租糧／佃戶對照
│年份 │租糧 │戶數 │
│ 183 │ 431 │ 136 │
│ 184 │ 420 │ 130 │
│ 185 │ 397 │ 122 │
│ 186 │ 368 │ 115 │
這不是單一田地的問題。
幾乎所有莊田，都在減戶。
只是有的快。
有的慢。
一開始，陸議以為自己會看到管理問題。
也許某些田地效率太低。
也許某些佃戶拖欠租糧。
可表格越整理，他越覺得不對。
田還在。
租制沒有大改。
甚至有些年份的每戶產出並不算差。
可人正在減少。
不是糧食先少。
是人先少。

福伯站在一旁，看他沉默太久，終於忍不住低聲問道：
「小公子，可是看出什麼了？」
陸議沒有立刻回答。
他只是指著表格上的一行。
「這一年，東田為什麼少了八戶？」
福伯低頭看去，雖看不懂那些數字，卻知道他問的是哪一年。
他想了想，才道：
「那年春夏之交，莊上鬧過一場病。」
陸議抬頭。
「病？」
福伯嘆了一聲。
「先是幾戶人家腹瀉發熱，後來傳開了。大夫去了，也只能開些湯藥。拖了一個多月，死了不少人。」
陸議的手指停住。
腹瀉。
發熱。
傳開。
春夏之交。
他又翻開另一卷租冊。
「西田這一年，也少了八戶。」
福伯沉默片刻。
「也是疫病。」
陸議再指向另一行。
「這裡呢？」
「那年更重。」
福伯聲音低了些。
「有幾戶整家都沒了。」
屋內忽然安靜下來。
窗外有風，吹得案上粗紙微微翻動。
陸議按住紙角，目光仍落在那幾行數字上。
在帳冊裡，這只是減戶。
在租冊裡，這只是少收幾十石糧。
可這些人死了，最先消失的不是姓名。
是勞力。
是租糧。
是陸家往後幾年的底氣。
減戶二十三。
不只是二十三個戶名從冊上消失。
而是可能有上百個人，就這樣從這個世界上消失了。
帳冊記得很清楚。
少了多少戶。
少了多少租。
卻沒有人真正去問。
為什麼會少。
又能不能少死一些。
在這個時代，瘟疫就像暴雨、旱災、蝗蟲一樣。
來了。
受著。
死了。
記上。
然後等下一年。
可陸議不習慣這樣。
他不是大夫，也不是神仙。
但他來自一個同樣有疾病、有死亡的世界。
那個世界也救不了所有人，卻知道一些最基本的事。
水要乾淨。
病人不能和所有人混在一起。
手髒了要洗。
這些在他的世界裡，普通到沒人會拿來誇耀。
可在這裡，也許就是佃戶減少與收糧增加的差別。

「那些病人，當時住在哪裡？」
福伯一愣。
「自然住在家中。」
「家人照顧？吃水從哪裡來？」
「是。莊旁有井，也有溪。」
「病人用過的東西呢？」
福伯皺眉，顯然不明白他為何這樣問。
「能用便用，不能用便丟。」
陸議沉默。
不是完整答案，但已經足夠。
病人留在家中。
家人照顧。
共用水源。
共用器具。
這不是誰的錯，甚至不是愚蠢。
只是這個時代，還沒走到那裡。
陸議低頭看著表格，心裡很快生出另一條更冷的線。
人少。
租少。
糧少。
陸家弱。
而陸家若繼續這樣弱下去，遠在廬江的那位族長，處境只會更加艱難。
廬江太守，陸康。
如今支撐整個陸氏一族，也是未來會獨自面對袁術大軍的人。
陸議很清楚，自己現在太小，沒有資格說話。
想讓那位真正的大人物看見自己，就不能只靠幾句童言。
得有結果。
能寫進帳裡，能放到族老面前，能讓人無法忽視的結果。
所以這件事必須處理。
至於那些因此活下來的人，那當然也很好。
但陸議首先看見的，是這些死亡正在拖垮陸家。

當晚。
陸議另取一張粗紙，在最上方寫下兩個字。
疫病。
然後把白天想到的，一一記在下面。
寫到「手」字時，他停住了。
飯前洗手。
如廁後洗手。
碰過病人要洗手。
這些他閉著眼都做得來。
可在這裡，要拿什麼洗？
他想起這幾日。
每回洗臉、淨手，下人都會遞來一樣東西。
褐黑，捏成小塊。
他接過來，在水裡一搓——
起泡。
去油。
手心的膩滑，清水一沖就掉。
那一刻他便明白了。
這東西，就是這個世界的「肥皂」。

陸議故意在指上抹了一道墨，然後對福伯說：
「福伯，我想洗手。」
福伯立刻道：
「我這就去拿皂角過來。」
皂角。
陸議在心裡，默默記下了這個名字。
他用了好幾日，卻是此刻，才知道它叫什麼。
——也罷。
叫什麼，不重要。
重要的是，它一直都在。

陸議盯著紙上那個「手」字。
他原以為最難的，是沒有東西可用，是要他從無到有變出個什麼。
可不是。
皂角就在這裡，人人都有，洗臉洗衣，天天在用。
東西，從來就不缺。
缺的是——
沒有一個人，把「洗手」當成一件非做不可的事。
皂角擱在那兒，是用來洗臉洗衣的。
從沒有人想過，它和那一條條往下掉的人命，能有什麼干係。
陸議慢慢放下了筆。
他真正要做的，不是發明。
是立規矩。
目光又落回另一行字上。
病人。
病人留在家中，共用一口井，共用一副碗筷。
只是洗手，還不夠。
只要病人還和好人混在一處，喝同一桶水，這條路就堵不死。
病人，得單獨安置，得有人專門照看，得和其餘的人隔開。

兩件事。
一件，是讓莊上的人，養成洗手的規矩。
另一件，是把病人從各家各戶裡，集中起來照料。
至於具體怎麼做，要用多少人，立哪些章程，他還要再細想。
但方向，已經定了。
而那些會因此活下來的佃戶——
他也不打算苛待。
人活著，才能耕田，才能交租，才能讓這個家慢慢緩過來。
把人當人，於他們有利，於陸家也有利。
這一點，他算得清清楚楚。

福伯在一旁看著，依舊不懂小公子盯著那幾行字，在想些什麼。
可他心裡隱隱覺得。
小公子這回要做的事。
大概又和帳房裡那些奇怪的格子一樣。
一開始，誰也看不懂。
可等看懂時——
事情，就已經不一樣了。
