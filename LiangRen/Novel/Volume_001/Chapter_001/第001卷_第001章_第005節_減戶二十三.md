《良人》

第一卷 江東初醒
第一章 立足
第五節 減戶二十三

二十年前的田契，最後還是送到了陸議面前。
不是全部。
至少不是一開始就全部。
陳管事很謹慎。
他送來的是吳郡各地的田契副冊，旁邊還附了近年的租冊、佃戶名冊與庫房進出簿。
這已經夠了。
陸議並不急著看更多。
資料不是越多越好。
沒有方法，資料越多，只會越亂。

而現在。
他的方法已經建立起來了。
案上鋪著幾張粗紙。
粗紙上畫滿方格。
每張紙左側是年份。
右側則是戶數、租糧、支出與庫存。
有些地方畫著圓圈。
有些地方畫著三角。
有些地方則標著問號。
福伯看不懂。
陳管事看不懂。
帳房先生也看不懂。
可對陸議而言。
那是他的索引。
他的標記。
也是他在這個時代暫時唯一能依靠的工具。
一卷卷帳冊被拆開。
一筆筆數字被重新填進表中。
起初只是東田。
後來是西田。
再後來，是附近幾處莊田。
當那些原本散落在竹簡與紙冊中的記錄，被重新排列到同一張粗紙上時，藏在流水帳裡的東西，終於開始浮出水面。
不是貪墨。
不是假帳。
也不是誰偷偷拿走了糧食。
而是一條不斷往下的線。
陸議看著粗紙上的表格，久久沒有說話。
東田租糧／佃戶對照
│年份 │租糧 │戶數 │
│ 183 │ 583 │ 182 │
│ 184 │ 612 │ 177 │
│ 185 │ 598 │ 169 │
│ 186 │ 541 │ 161 │
西田租糧／佃戶對照
│年份 │租糧 │戶數 │
│ 183 │ 431 │ 136 │
│ 184 │ 420 │ 130 │
│ 185 │ 397 │ 122 │
│ 186 │ 368 │ 115 │
這不是單一田地的問題。
幾乎所有莊田，都在減戶。
只是有的快。
有的慢。
一開始，陸議以為自己會看到管理問題。
也許某些田地效率太低。
也許某些佃戶拖欠租糧。
也許某些管事做事敷衍。
可表格越整理。
他越覺得不對。
田還在。
租制沒有大改。
甚至有些年份的每戶產出並不算差。
可人正在減少。
不是糧食先少。
是人先少。

福伯站在一旁，看他沉默太久，終於忍不住低聲問道：
「小公子，可是看出什麼了？」
陸議沒有立刻回答。
他只是指著表格上的一行。
「這一年，東田為什麼少了八戶？」
福伯低頭看去。
雖然看不懂那些奇怪數字，卻知道陸議問的是哪一年的帳。
他想了想，才道：
「那年春夏之交，莊上鬧過一場病。」
陸議抬頭。
「病？」
「嗯。」
福伯嘆了一聲。
「先是幾戶人家腹瀉發熱，後來傳開了。大夫去了，也只能開些湯藥。拖了一個多月，死了不少人。」
陸議的手指停住。
腹瀉。
發熱。
傳開。
春夏之交。
他沒有說話。
只是又翻開另一卷租冊。
「西田這一年，也少了八戶。」
福伯沉默片刻。
「也是疫病。」
陸議再指向另一行。
「這裡呢？」
「那年更重。」
福伯聲音低了些。
「有幾戶整家都沒了。」
屋內忽然安靜下來。
窗外有風。
吹得案上粗紙微微翻動。
陸議伸手按住紙角。
目光仍落在那幾行數字上。
在帳冊裡。
這只是減戶。
在租冊裡。
這只是少收幾十石糧。
可這些人死了，最先消失的不是姓名。
是勞力。
是租糧。
是陸家往後幾年的底氣。
減戶二十三。
不只是二十三個戶名從冊上消失。
而是可能有上百個人。
就這樣從這個世界上消失了。
陸議忽然覺得有些荒謬。
因為帳冊記得很清楚。
少了多少戶。
少了多少租。
少了多少糧。
卻沒有人真正去問。
為什麼會少。
又能不能少死一些。
在這個時代。
瘟疫似乎就像暴雨、旱災、蝗蟲一樣。
來了。
受著。
死了。
記上。
然後等下一年。
可陸議不習慣這樣。
他不是大夫。
也不是神仙。
但他來自一個同樣有疾病、有災難、有死亡的世界。
那個世界也救不了所有人。
可至少知道一些最基本的事。
水要乾淨。
吃的東西要乾淨。
病人不能和所有人混在一起。
手髒了要洗。
糞污不能靠近水源。
這些在他的世界裡，普通到沒人會拿來誇耀。
可在這裡。
也許就是佃戶減少與收糧增加的差別。

福伯見他臉色不對，低聲道：
「小公子？」
陸議回過神。
「那些病人，當時住在哪裡？」
福伯一愣。
「自然住在家中。」
「家人照顧？」
「是。」
「吃水從哪裡來？」
「莊旁有井，也有溪。」
「病人用過的東西呢？」
福伯皺眉。
顯然不明白他為何這樣問。
「能用便用，不能用便丟。」
陸議沉默。
他已經大概明白了。
不是完整答案。
但足夠讓他知道，問題可能在哪裡。
病人留在家中。
家人照顧。
共用水源。
共用器具。
糞污與飲水未必分開。
死去的人，也未必能被妥善處理。
這不是某個人的錯。
甚至不是愚蠢。
只是這個時代還沒走到那裡。
陸議低頭看著表格。
心裡很快生出另一條更冷的線。
人少。
租少。
糧少。
陸家弱。
而陸家若繼續這樣弱下去。
遠在廬江的那位族長，處境只會更加艱難。
廬江太守。
陸康。
如今支撐整個陸氏一族的男人。
也是未來會獨自面對袁術大軍的人。
陸議很清楚。
自己現在太小。
沒有資格說話。
更沒有資格改變什麼。
想讓那位陸氏真正的大人物看見自己。
就不能只靠幾句童言。
得有結果。
能寫進帳裡。
能放到族老面前。
能讓人無法忽視的結果。
所以這件事必須處理。
至於那些因此活下來的人。
那當然也很好。
但陸議首先看見的，是這些死亡正在拖垮陸家。

當晚。
陸議沒有再翻田契。
他另取一張粗紙。
在最上方寫下兩個字。
疫病。
然後在下面一行一行列出問題。
水。
食。
手。
糞。
病人。
屍體。
隔離。
每寫下一項。
他都停頓片刻。
將自己想到的方法一一記在旁邊。
寫到「手」字時。
陸議忽然停住。
他想起一件極普通的事。
在原本的世界。
飯前洗手。
如廁後洗手。
接觸病人後洗手。
這些幾乎不用思考。
可這裡沒有肥皂。
至少沒有他熟悉的肥皂。
陸議皺起眉。
肥皂沒有。
那有沒有替代品？
去污。
發泡。
能洗手。
他腦中忽然閃過一個模糊的名字。
皂莢。
他記得那東西似乎可以起泡。
似乎可以洗滌。
可到底能不能用。
怎麼用。
要不要磨碎。
要不要煮水。
比例多少。
他並不確定。
不確定。
就只能驗證。
陸議擱下毛筆。
抬頭看向福伯。
「福伯。」
福伯一直守在旁邊，聽見聲音立刻上前。
「小公子？」
陸議問：
「府裡可有藥園？」
福伯愣了一下。
「有。」
「有沒有皂莢？」
「皂莢？」
福伯更加疑惑。
「那是藥材。小公子問這個做什麼？」
陸議低頭看了一眼粗紙上的「手」字。
又看了一眼那幾行不斷減少的佃戶。
過了片刻。
他才輕聲說：
「我想試試。」
福伯聽不明白。
但他忽然覺得。
小公子這一次想試的東西。
也許和帳房裡那些奇怪的格子一樣。
一開始看不懂。
可等看懂時。
事情就已經不一樣了。
