《好人？》

作者   攻城師

第一卷 江東初醒
第一章 立足
第四節 惡魔藏在紀錄裡。

族老走後的第二日，陸議頭一回，主動離了自己的院子。

去處，是帳房。

＊

消息很快傳了進去。

陳管事正低頭核著租冊，聽僕役稟報時，手裡的筆微微一頓：「小公子要看帳？」

旁邊幾名帳房先生也愣了愣，隨即有人失笑：「小公子今年才五歲吧？五歲就想學管家啦？」

帳房裡響起幾聲善意的笑。

陳管事也笑了，隨手從架上取下幾卷近三年的總帳：「孩子總有好奇的時候。拿去吧——若看不懂，就當故事翻翻。」

福伯抱起帳冊，沒多說什麼，轉身去了。陳管事低下頭，繼續核他的帳。這樁小事，很快就被拋到了腦後。

＊

一個時辰後，福伯又來了。

「小公子看完了。」

陳管事抬起頭：「看完了？」

福伯點點頭。

陳管事笑了笑：「那就再拿幾卷。」

第二批帳冊送了出去。不到半個時辰，福伯又出現在門口。

這回，帳房裡的人有些詫異了。

「又看完了？」

福伯苦笑：「又看完了。」

眾人面面相覷。陳管事卻仍不以為意：「孩子新鮮勁重，過兩日就膩了。」說著，又取了幾卷帳冊出去。

然而，事情並沒有照他料想的走。

帳冊送出去的間隔，越來越短。起先，陸議還要反覆翻閱，有些地方甚至問了福伯好幾遍；可漸漸地，僕役來討帳冊的腳程越來越勤——帳房先生一盞茶還沒喝完，那頭又跑來了：「福伯說，小公子還要。」

有人忍不住打趣：「這是看帳，還是吃飯呢？」

另一個接話：「照這個速度，再過幾日，帳房怕是要被搬空嘍。」

眾人都笑了。陳管事也笑著搖了搖頭，只當是孩子一時新鮮——過兩日，也就膩了。

＊

然而接下來的五日，把陳管事那點「過兩日就膩了」的篤定，一日一日地，磨了個乾淨。

那孩子，竟沒有一日停歇。天剛亮，帳冊就討了去；他夜裡起身經過內院，那盞燈，還亮著。福伯來來回回地跑，跑得他這偌大的帳房，上下不得安寧。

起先，陳管事還當是孩子貪個新鮮。可討到第三日，他就笑不太出來了——那孩子討的帳，變了。先是近年的總帳，後來是租冊，再後來是庫房簿、佃戶名冊；到了第五日，竟開口，要起二十年前的舊帳來。

這哪裡還是一個孩子的好奇。

可要說在查什麼，又不像。他也說不上來——那孩子，倒像是在把什麼東西，一件一件，理到一處去。

陳管事心裡，頭一回，有些沒了底。

＊

到了第五日傍晚，他到底按捺不住，親自往內院走了一趟。

院門半掩著。他從門縫裡看進去，不由微微一怔。

院裡靜悄悄的，案上堆滿了竹簡與紙冊。陸議正趴在桌前，左手翻著帳，右手捏著一截削細的毛筆，在粗紙上不停地寫。

那紙上，畫滿了方方正正的格子，不像字帖，倒像個棋盤。每個格子裡都填著些古怪的符號——既不是隸書，也不是篆字，是他這輩子從沒見過的東西。

其中一張粗紙，最上頭寫著：

　　東田租糧
　　│ 年份 │ 租糧 │
　　│ 183 │ 583 │
　　│ 184 │ 612 │
　　│ 185 │ 598 │
　　│ 186 │ 541 │

旁邊另一張，則是：

　　東田佃戶
　　│ 年份 │ 戶數 │
　　│ 183 │ 182 │
　　│ 184 │ 177 │
　　│ 185 │ 169 │
　　│ 186 │ 161 │

而第三張紙上，原本散在好幾卷帳冊裡的東西，竟被並到了同一張紙上：

　　東田・租糧／佃戶對照
　　│ 年份 │ 租糧 │ 戶數 │
　　│ 183 │ 583 │ 182 │
　　│ 184 │ 612 │ 177 │
　　│ 185 │ 598 │ 169 │
　　│ 186 │ 541 │ 161 │

陳管事一個字也認不得。

可他看得出來——原本散落在十幾卷帳冊裡的數目，如今竟被濃縮進了這薄薄三張紙。更叫他心裡發毛的是，那些數字彼此之間，像是藏著某種說不清的牽連，他卻怎麼也看不透。

那感覺，就像盯著一盤棋，卻全然猜不出對手下一子要落在哪裡。

再加上紙邊那些莫名的記號——○、△、×、？——他就更是一頭霧水了。

可有一樣，他是看懂的：桌上那堆帳冊，被重新分了門類。田租一堆，庫房一堆，佃戶一堆，人情往來又是一堆，整整齊齊，井井有條。

彷彿有一雙看不見的手，正把這散亂了二十年的東西，一件件拆開、排過、重新組起來。

＊

陸議像是察覺了什麼，抬起頭，看見門縫外的陳管事，微微一點頭：「陳管事。」

陳管事愣了一下，忙拱手：「小公子。」

陸議沒再多說，低下頭，接著整理手上的東西——彷彿站在門外的，不是陸家的帳房主管，只是個路過的閒人。

陳管事在原地立了片刻，終究還是問了出口：「小公子……這是在做什麼？」

陸議頭也沒抬：「找規律。」

「規律？」陳管事微微皺眉。

陸議沒有解釋。因為他忽然發現，自己竟找不出一個合適的詞來。

在他來的那個世界，這不過是再尋常不過的事——把一堆零散的數目理清、比對、看出裡頭的門道。可在這東漢末年，似乎還沒有人想過，要從一堆散亂的記錄裡，把事情原本的模樣，一點一點拼回來。

於是他只淡淡道：「把東西，放到該放的地方。」

陳管事聽了，沒有再問。

這話聽著再樸實不過——可他心裡清楚，這滿桌子的東西，本就都在「該放的地方」：租冊在租冊架上，庫簿在庫簿匣裡，二十年來，一直都是這麼擺的。是這孩子，把它們全掀了、拆了，又照著另一套他看不懂的章法，重新擺了一遍。

而擺完之後，那些數目，仿佛就自己開口說起話來了。

只是那話，他一個做了二十年帳的人，一個字也聽不懂。

因為他忽然意識到，自己不但看不懂桌上那幾張紙，也看不懂眼前這個五歲的孩子了。

＊

回到帳房，陳管事本想接著處理手邊的事，卻遲遲落不下筆。案上的帳冊攤開了許久，筆尖的墨，都凝住了。

一名帳房先生見他這副模樣，忍不住問：「管事？」

陳管事回過神：「嗯？」

「小公子那頭……如何了？」眾人都露出好奇的神色——這五日，整個帳房都快被那孩子折騰瘋了。

陳管事沉默了半晌，最後只吐出三個字：「不知道。」

眾人一愣：「不知道？」

陳管事望向窗外。

他腦子裡翻來覆去的，是那滿桌的竹簡，那些認不得的符號。

起先，他只當那是個孩子。後來，他當那是孩子的一時興起。

可到了此刻，他頭一回，有些拿不準了。

他做了二十年的帳，見過精明的人，見過貪心的人，也見過裝傻的人。可他從沒見過一個五歲的孩子——能讓他這個做老了帳的，在自己守了二十年的帳房裡，覺得心底發涼。

＊

正在這時，帳房外忽然響起一陣急促的腳步聲。

眾人一齊抬頭。

下一刻，福伯出現在門口。

帳房先生們面面相覷，心裡莫名生出一股不祥的預感。

果然，福伯乾咳了一聲，有些不好意思地開口：「小公子說……還要帳。」

帳房裡瞬間靜了。

陳管事沉默片刻，終於放下手中的筆，第一次，親自站起了身。

「這回。」他問，「他要什麼？」

福伯低頭看了看手裡那張紙條，神情有些古怪：「……二十年前的田契。」

話音落下，帳房裡霎時鴉雀無聲。

因為那已經不是帳了。

那是陸家的根。
