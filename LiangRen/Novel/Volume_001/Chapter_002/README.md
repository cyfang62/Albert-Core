# ★ §33／§34 筆記

## §33〈我就埋個種子。〉（農曆五月末·距§32五日）

**兩場戲，同一顆種子。**

* **晚飯桌**：陸議只如實報「今日去看了誰」——耿順（耿老之子）、吳隊長的小兒子，都是自己來的。**不加一句評論、不下任何結論。**
  - ★陸康問「他們的娘，可願意」→「**我沒敢問**」→「你倒是分得清，哪些話該問，哪些話不該問」。
  - ★★收於陸康自己說出：「**既是自己想清楚了，便由他去。**」
  - ★★**種子＝機動隊裡每一個名字，都是一個家庭。** 這顆種子在 §34 陸康讀陳溫的信時發芽。
* **翌日·道南大宅**：孫堅獲封破虜將軍、領豫州刺史。
  - 先給喜悅→★補「只說袁術**表**了，**沒說朝廷准了**」→周瑜解「表」與「封」→★「**袁術需要一把刀。一把鋒利無比的刀。**」→★★「**不是膽子。他是在告訴別人，他有為所欲為的能力。**」
  - ★★**孫策的自照**：「我怕的，從來不是我爹被人騙。我怕的是——**袁術給他的那個理由，他信了**。」
  - ★周瑜追問「令尊當年可曾是那種會被人牽著走的人」＝**越界**（在朋友傷疤上撒鹽）→★陸議一眼制止、不接話→孫策察覺「你們兩個是不是都想到了什麼卻都不說」→★★**陸議忽然站起身**（**用動作截止話題**）「這些都只是猜測。**你父親人在魯陽，人好好的**」。
  - ★收尾：耿順的名字第二次使用——「他想清楚了。**你不也是嗎？**」→孫策想起安豐那夜自己喊的「**廬江在此**」→「機動隊裡，我會護著他。」

## §34〈承諾也是一種目標。〉（五月末→六月初）

**三段：十來個尋常日子／陳溫的信／五日後的質問。**

* **陳溫請兵**（史實：曹洪就溫募兵得「廬江上甲二千人」·**史書未載陸康角色，此為本作填補**）：客氣、包著大義、「不敢以刺史之位相逼」。
  - ★陸議四問：「兵借給誰？」「**是有個人叫大義，要來領兵嗎？**」→「誰帶、帶去哪裡、打哪一場，也都沒寫」→★★「**這些人……還回得了家嗎？**」
  - ★★陸康：「**這世道，最不缺的，就是打著大義旗號、要別人拿命去填的人。**」（★§33那顆種子在此發芽——他想起的是耿順、吳隊長的小兒子、安豐那夜）
  - ★★**陸議遞台階**：「祖父又沒說不借。……**借兵之事，先緩一緩。**」→**不拒，只緩**。
    - ★**台階是給陸康的**，不是給陳溫的：讓他不必在「服從上司」與「守住廬江」之間做非黑即白的選擇。
  - ★★**藏拙第四式·反向歸功**：「這話是誰教你的？」→「**祖父啊。**上回關東諸軍起兵那封信，祖父看完就收起來了，也沒回。後來酸棗自己就散了。」→陸康心裡起疑（**這話說得太順了**），選擇不戳破。
  - ★★**門邊那一句**：「祖父。**其實你也在乎那個賣餅的。不然，你就不會替他擔著這些了。**」——★全書至今兩人最接近彼此的一次。
* **五日後·質問拒兵**（消息來自**周家情報網**，非陸議告知）：
  - ⚠️★**周瑜與孫策都是認為董卓該討的人**——這是真實的立場衝突，不是誤會。
  - ★★**最重的一擊**：「**安豐那一仗才過去多久？你們真的覺得，廬江現在的兵……夠嗎？**」→★孫策想起**還在養傷的周泰**與**耿老最後那句遺言**，手慢慢鬆開。
  - ★★**承諾（節名出處）**：「哪天廬江真的兵足了，你們兩個**若**要領兵討董……**打完了，把弟兄們帶回家。**」→「**耿順他娘，也在等他回家。**」
  - ★★**兩種說服路徑並列**：孫策靠**具體記憶**被打動（說出口、記下來）；周瑜靠**邏輯缺口**被說服（自己完成推理鏈，然後安靜下來）。★**周瑜「懂了就沉默」是個性，不是反應不足。**
  - ★★**收尾**：馬車上，「陸議看著漸漸遠去的周家，**嘴角微微揚起**，拉下車簾。」⚠️**動機留白，不替他下結論。**


## §35〈別搞錯重點了。〉（六月中·距§34約十日·⚠️未跨月不結算）

**一節輕鬆的間奏，最後一行留了一根刺。**

* **朱桓**（虛歲14·睽違兩年）隨吳郡朱氏商隊來拓商路。★**不遞帖子、只報名字**：「舒縣朱桓，找陸議」「敘舊」。
* ★★**外人視角丈量廬江（本節功能核心）**：關津稅則刻在木牌上、誰過都一個價；田裡溝渠、路上轍痕修得齊整——「**不是那種面子工程，是真有人一寸一寸弄過的**」。★**廬江的治理成果，第一次被一雙外來的眼睛確認。**
* ★**安豐的外部版本**：朱桓路上聽到的是「守軍死守不退，你這麼小也跟著沒走」。⚠️**「自身為餌」全書至今僅周瑜知道。** 陸議只答四個字：「**因為不能走。**」
* ★**見周泰**：朱桓收回要拍肩的手、改拱手稱「周兄」（★**周泰21歲，長他七歲**）。★★周泰：「**有些事，比這條胳膊要緊。**」→朱桓：「**你這樣的人，朱桓服。**」
* ★**路上**：「真到了該留下的時候——他們都不會走。」→朱桓：「**『留下不走』這四個字，不是哪個門第能教出來的。**」→★★陸議近乎自語：「**把像朱大哥這樣的人，都聚到一起。**」→朱桓沒接話，一把搭肩，只說一個「行」。
* ★**見孫策周瑜**：★孫策傷口已癒、不再吊繃帶，只是左臂偶爾收著勁。★★朱桓的判詞：「**如今話多了，笑得也輕鬆了——可藏的東西，反而更深。**」→陸議踢石子、岔開（**節名出處**），把場子交給刀法與棋局。
* ★★★**收尾（全節最重）**：
  > 陸議站在稍遠處，看著這一幕。／心裡卻只閃過一句話。／——**其實，自始至終，我藏著的，只有一件事。**
  - ★**只說給讀者聽**，廳裡無人聽見。★**「只有一件事」**——所有藏拙與算計，全部只為遮住同一樣東西。⚠️**不得代為點破。**

# ★ 本章方法論（累積）

* ★**一個名字，四種花**：耿順在 §33／§34 出現四次，功能全不重複——①讓陸康把編制與家庭連起來②照見孫策自己的選擇③輕鬆的近況（拒信前的第二次澆水）④孫策承諾的具體對象。
* ★**動作截止話題**：要中斷一個話題，用動作（站起身），不用旁白說明。**「我為啥突然站起來？」——因為情緒已經堆到必須有人出手。**
* ★**著作權讓渡的第四種方向**：以往是把自己的功勞讓給別人（周瑜、陸康）；§34 是**當面對著陸康本人，把自己的創見說成是模仿他**。
* ★**「若」字的分寸**：承諾要留選擇權給對方。★**唯一的「要求」不是怎麼打，是「把弟兄帶回家」**——那不是命令，是託付。
* ★**外人視角是校準器**：讀者對日常成果會麻木，換一雙沒看過的眼睛看一次，價值才會重新被感覺到。
* ★**不說出來的最重**：「只有一件事」——沒說出那是什麼，威力才最大。
