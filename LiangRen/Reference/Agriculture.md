# Historical Limitation

小說應符合：

建安年間的農業水準。

即使陸議知道現代農業知識，

仍受限於：

* 工具
* 材料
* 勞力
* 社會制度
* 技術傳播

不得直接實現超越時代的大規模農業改革。

---

# Agricultural Decision

若主角希望改善農業，

需評估：

* 是否具備知識。
* 是否取得土地。
* 是否有人力。
* 是否能取得工具。
* 是否符合季節。
* 是否符合當地自然環境。

知識本身，

不等於立即提升產量。

# 拓墾良田（產權不動·勘測服務·分帳誘導）研究（§6起）

Topic

郡府主導的荒地開發：不奪產權，以服務與分帳誘導世家自願開墾

Source

史上屯田/勸農概念 ＋ 前世「以誘因對齊各方利益」的機制設計

Summary

* 產權鐵律：世家的地還是世家的、官府的地還是官府的，無土地易主。
* 執行：對外稱「多種糧」；先踏勘（實地看非訪）官府荒地→畫地籍、分甲乙丙丁、甲級優先。
  官府荒地由官民逐一往外墾；世家荒地由其佃戶墾。
* 分帳（官府協助墾世家甲等地、缺勞力時）：甲4(世家)/6(官府)、乙3/7、丙2/8、丁1/9。
  ★反直覺：地越好官府分越少、地越差官府分越多。機理：逼世家搶著讓官府幫墾好地（產出最大、稅基做大）、
  劣地官府拿9成幾乎獨吞（變新糧源）。
* 陸家帶頭：陸家先把撂荒地拿出來當餌、以身作則，逼世家自願跟進（「若連陸家都捨不得，又怎能勸旁人？」）。

Historical Limitation

須符合東漢農業水準（工具、勞力、季節）；開墾見效需時間，非即時。入夏時春耕已過、農閒操演需待夏收後。

Novel Usage

§6結尾啟動（陸家帶頭·陽謀切片）；分帳反直覺為§7正片。研究性細節此處，正文只挑勾人切片。

Notes

與 Economy.md（稅基/分帳經濟邏輯）互見。與 WorldBible/Estate.md（吳郡陸家庄田·不同層級）區分：此為廬江郡級拓墾。
