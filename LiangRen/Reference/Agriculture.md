# Purpose

本文件整理《良人》創作所需的農業研究資料。

目的不是建立小說設定，

而是提供：

* 農業考據
* 作物研究
* 農具資料
* 耕作方式
* 水利技術
* 糧食生產

供小說創作時參考。

正式採用之設定，

仍以小說內容與 WorldBible 為準。

# Historical Limitation

小說應符合：

建安年間的農業水準。

即使陸議知道現代農業知識，

仍受限於：

* 工具
* 材料
* 勞力
* 社會制度
* 技術傳播

不得直接實現超越時代的大規模農業改革。

---

# Agricultural Decision

若主角希望改善農業，

需評估：

* 是否具備知識。
* 是否取得土地。
* 是否有人力。
* 是否能取得工具。
* 是否符合季節。
* 是否符合當地自然環境。

知識本身，

不等於立即提升產量。
