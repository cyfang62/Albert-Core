# LiangRen World Bible

# Purpose

本文件定義《良人》的地理設定。

目的不是完整介紹東漢地理。

而是建立小說中所有重要地點的共同設定，確保各章節對地理位置、行政區劃與距離的描述保持一致。

Geography 為《良人》唯一的地理基準。

---

# Timeline Reference

故事開始時間：

**建安元年（西元 196 年）**

所有行政區與地名，

皆以此時期為主要設定。

---

# World Overview

目前小說主要舞台位於：

```text
東漢

└── 揚州
     └── 吳郡
```

故事初期，

主要活動範圍集中於：

陸府、

吳郡城、

以及周邊地區。

---

# Administrative Structure

```text
東漢
│
├── 州
│
├── 郡
│
├── 縣
│
└── 鄉、里
```

《良人》採用東漢行政制度。

小說若涉及官職與行政區，

皆應符合當時制度。

# Current Locations

---

## 揚州

Type

州

Description

江東主要行政區域。

包含多個郡，

為小說中後期的重要舞台。

---

## 吳郡

Type

郡

Description

陸氏家族所在地。

亦為小說第一卷主要舞台。

Features

* 江東重要郡治
* 世族聚集
* 商業發展
* 水路便利

---

## 陸府

Type

Residence

Location

吳郡

Description

陸氏家族宅邸。

故事開始的主要場景。

目前已知：

* 前院
* 中庭
* 書房
* 內宅
* 客廳（可依後續章節補充）

# Distance Rule

目前小說，

不建立精確距離。

採用：

相對距離。

例如：

* 府內
* 城內
* 郡內
* 州內
* 跨州

若後續劇情需要，

再建立旅行時間與路線。

---

# Travel Principle

人物移動，

需符合：

* 當時交通工具
* 地理位置
* 合理旅行時間

不得出現：

短時間跨越過遠距離，

除非劇情另有合理說明。
