# Core Finding（第005節核心結論）

陸議整理上述數據後，

得出的根本判斷：

> **不是糧食先少，是人先少。**

* 田還在。
* 租制沒有大改。
* 部分年份每戶產出並不算差。
* 但佃戶戶數持續下降。

問題不是管理、不是貪墨、不是假帳，

而是**佃戶人口在減少**。

---

# Root Cause：疫病

減戶的根本原因為**歷年疫病**：

* 多發於春夏之交。
* 症狀為腹瀉、發熱，會傳開。
* 大夫只能開湯藥，往往拖一個多月，死者眾多。
* 某些年份更重，有整戶滅絕者。

累積結果：

> **減戶二十三**——
> 不只是冊上少了二十三個戶名，
> 而是可能上百口人，就此消失。

---

# Hygiene Conditions（莊上現況，第005節）

陸議查出的衛生問題：

* 病人留在家中。
* 由家人就近照顧。
* 共用水源（莊旁有井，也有溪）。
* 病人用過的器具「能用便用，不能用便丟」。
* 糞污與飲水未必分開。
* 死者未必能被妥善處理。

> 此非某人之過，亦非愚蠢，
> 只是這個時代尚未具備衛生與感染的概念。

這些條件，

是第006節以降「衛生介入」的問題根源。

---

# Economic Logic（陸議的動機鏈）

陸議介入此事的動機，

正文已寫明，且須維持其「自利」純度：

```text
佃戶減少
  → 租糧減少
  → 陸家變弱
  → 這一房更易被代管、被分食
```

因此：

> 壓低佃戶死亡率
>   → 人口回升
>   → 租糧回升
>   → 帳冊數字好看
>   → 讓上層（族中、廬江陸康）看見自己
>   → 換取話語權、不被代管

「那些因此活下來的人，當然也很好」——

但這是結果，不是動機。
