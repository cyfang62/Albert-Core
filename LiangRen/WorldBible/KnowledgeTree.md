# Purpose

本文件定義《良人》主角陸議的 Knowledge Tree（知識樹）。

目的不是紀錄所有知識。

而是記錄：

> **目前陸議知道什麼、理解到什麼、能做到什麼。**

Knowledge Tree 為小說中所有 Decision 的知識基礎。

任何行動，

皆應建立於主角當下已掌握的知識。

# Core Principle

知識不等於能力。

能力不等於成果。

因此：

```text
Knowledge
    ↓
Understanding
    ↓
Decision
    ↓
Action
    ↓
Result
```

小說中不得跳過此流程。

## 皂莢洗滌法

來源

前世記憶（知道皂莢可去污）＋ 自身驗證

驗證節次

第一卷第一章第006節

過程

* 第一次：整顆浸泡 → 無效。
* 第二次：搗粉入水攪拌、放涼過濾 → 去污力弱、泡沫少。
* 第三次：搗粉入水攪拌、**加熱**、放涼過濾 → 起泡、去污成功。
* 第四次：重複第三次步驟 → 結果一致，確認可重現。

已確認方法

```text
搗粉 → 入水 → 攪拌 → 加熱 → 放涼 → 濾淨
```

狀態

> **已驗證（可重現）。**

限制／待解

* 僅完成「製作」驗證。
* 「推廣」尚未解決——佃戶民智未開、不信感染概念，
  如何讓人願意照做，為第007節以降的核心難題。

# Knowledge Limitation

即使知道未來，

仍受限於：

* 五歲身體
* 身分地位
* 時代科技
* 人力
* 資源
* 資訊取得
* **社會接受度（他人是否願意相信）**

Knowledge 不代表：

可以立即改變世界。

# Forbidden Knowledge

小說中不得出現：

* 無來源知識
* 突然學會的新能力
* 超出時代限制的科技
* 違反既有設定的知識

所有知識皆應符合故事發展。

---

# Review Checklist

新增任何知識前，

請確認：

* 是否已有來源？
* 是否符合角色年齡？
* 是否符合故事時間？
* 是否符合當代科技？
* 是否會影響後續劇情？
* 是「知道」還是「已驗證」？（決定歸入哪一區）

若以上任一項為否，

請重新評估。

每一次 Decision，
