## 衛生規矩介入

來源

前世衛生／感染常識 ＋ 既有可用之物（皂角）＋ 自身決策推動

驗證節次

第一卷第一章第006節〈規矩〉

內容

* 立洗手規矩：飯前、如廁後、接觸病人後須洗手；
  皂角由莊上備齊，一戶戶免費發放。
* 設病人集中照護：將病者自各家挪出，
  安置於遠離井溪、乾淨通風之處；
  另聘照護者（非病家），進出淨手、戴麻布夾紙之布；
  病人器具一律滾水煮過；探病限時，進出淨手。

驗證方式

> 非實驗室式驗證，而是以**結果**驗證：
> 第006節當季季帳顯示——他莊照舊死人，唯陸家莊死者寥寥，
> 人未減、租未缺。成效由帳面數據確認。

狀態

> **成效已驗證（由當季季帳佐證）。**

附註

* 皂角（皂莢）為東漢既有常見去污之物，
  非陸議發明、亦非實驗所得；
  陸議只是將它從「洗臉洗衣」用途，納入「衛生防疫」的規矩之中。
* 「推廣」問題已於本節解決：憑少主身分立規矩、主家親手免費發放，
  佃戶反較管事更當回事（「主家發的、又立了規矩，誰敢不洗」）。

> 註：原規劃中「實驗／奇蹟／見證」之敘事結構，
> 不歸於皂莢，改由日後「淨水器」承載。
> 本區不得再出現任何「皂莢實驗」成果。

## 濾水器

來源

現代常識（砂炭濾水古法）＋自身動手調試

驗證節次

第一卷第一章第007節〈入局〉

內容

* 一口大缸、缸底鑿孔，內由下而上碼：粗石／細沙／木炭（先燒透洗淨）／麻布鋪面。
* 濁水自上倒下，層層滲落，自缸底孔淌出時已清。
* 首試失敗（底石太大，水從石縫直穿、未過細沙），換小石鋪密、上添一層沙後成功。

能與不能（**關鍵，不得混淆**）

> * **能**：去濁、去異味——使濁臭之水變清、能入口，讓人肯喝、敢喝。
> * **不能**：**殺不掉水中致病菌**。真正要人命的細菌，濾水器濾不掉。
> * 真正殺菌者為「煮沸」（第008節鋪推）；濾水器管入口、煮沸管殺菌，兩者配套。

狀態

> **已做成、已驗證能濾清濁水（第007節）；本節僅做成，尚未大規模鋪推（留第008節）。**

附註

* 濾水器是「給眼睛看的」鉤子——清水看得見，用以說服民智未開的佃戶願改；
  真正壓低死亡曲線的是不起眼的煮沸。世人易將功勞記在濾水器上，陸議不更正。
* 敘事分層：對莊裡人藏（只說「看不見的髒」），對讀者不藏（明言「細菌」）。

# 歷史錨：飲湯／煮沸（第008節預埋）

第008節陸議推行「飲水一律煮沸」。此**非發明新技術**，而是三層操作：

## 一、技術層：零創新
煮水、飲熱水，先秦已有，材料方法全是現成，陸議未發明任何東西。
* 史料：《孟子・告子上》有「冬日則飲湯，夏日則飲水」——「湯」古義即燒滾之熱水；
  戰國至秦漢《黃帝內經》有「湯液」之說；《周禮》另記投熱石入水以滅蟲防疫。
  → 「喝熱水／飲湯」作為日常與養生習慣，先秦已然，漢代承之。

## 二、時間層：提早約百年
把「煮水」明確綁上「防病」的**明文**，晚至東晉張湛《養生要集》
（有「凡煮水飲之，眾病無緣生也」之語），約在188年之後一個半世紀。
* → 故188年陸議推煮沸，是把一個零散的養生習慣，**提早百餘年制度化為防疫規矩**。
  他偷跑的不是技術，是「普及的時程」。
* 界線（重要）：188年當時，人們知道的是「喝熱水（養生）」，
  **不是**「煮沸消毒防疫」的明確因果；後者屬陸議私藏的現代認知。
* 另注：陸羽《茶經》按水源分潔淨等級（山水上、江水中、井水下）為**唐代**（八世紀），
  與007「主家井 vs 溪」雖似，不可引為漢代之錨。

## 三、認知層：只頒規範，不告原理
陸議只下「飲水一律煮過」的規矩，不解釋「因為水裡有看不見的細菌」。
世人照做，不知其所以然——與006皂角、007濾水器同一手法：**給行為，藏機制**。

## 藏拙對答範本（標準口吻）
> 問：為什麼你覺得茶水要煮過？
> 答：「跟肉和菜一樣，煮過的『可能』比較不會生病。我只是『覺得』這樣而已。」

拆解（日後陸議解釋任何超時代舉措，皆照此模子）：

1. **類比降維**：掛到人人都懂的現成經驗（生肉生菜會壞肚子，煮過就沒事），不提水、不提細菌。
2. **降格確定性**：用「可能」「我只是覺得」，把百分百確定的機制，降成孩子沒把握的直覺——對方無從追問。
3. **留錯給對方填**：讓聽者自行補成「這孩子心細」，而非「他懂微生物」。

> 反諷（讀者層）：讀者知道那不是「覺得」，是他爛熟於心的東西。
> 世人聽見一個孩子的直覺，讀者聽見一個中年人在裝傻。

# 演兵（象棋・提早帶來之物）

陸議帶入的一套對弈：**象棋**。象棋定型於北宋，陸議提早搬至漢末。

## 定位：非發明，乃「提早＋在地化」
* 比照煮沸：不是憑空造物，是把一個本該晚出現的東西提早搬來。
* **藏拙空間比煮沸更大**：象棋演化漸進、模糊（先秦已有六博、塞戲等博戲），
  **無明確史料界線**。漢末之人只會當成「這孩子搗鼓的新奇博戲」，
  可信是他自己琢磨的——無人能指其時代破綻。
* **在地化**：兵種名一律改用三國軍營建制，抹去宋代痕跡，長進這個時代的皮肉。

## 名稱
**「演兵」**——不叫「棋」。取其「每一局都是演一場兵」的動作感；
既勾武膽少年（是打仗，不是遊戲），又進一步淡化「棋」的既有博戲聯想。

## 七子（三國建制命名 × 走法對照）

**設計原則：每一子的走法，都從「這種兵實際怎麼打仗」推出——聽的是道理，不是背規則。**

| 演兵 | 對應象棋 | 兵種道理 → 走法 |
| ---- | -------- | -------------- |
| 將軍 | 將／帥 | 主帥坐鎮中軍、不輕動 → 限中軍方寸（九宮），一步一格 |
| 親衛 | 士 | 貼身護主、寸步不離 → 九宮內斜護，出不了那方寸 |
| 參軍 | 象／相 | 執掌中軍號令、調度諸營，不得擅離中軍 → **不過河**（若過河，誰替主將傳令？義理與走法契合） |
| 鐵騎 | 車 | 馬快、善衝鋒 → 直線長驅，一衝到底 |
| 戟士 | 馬 | 長戟招在旁勾 → 走日字斜擊；**但貼身（鄰子擋）便勾不過**（＝蹩馬腿；理由：人一貼近，長戟施展不開） |
| 強弩 | 炮 | 弩拋射、越陣及後 → **隔一子而射**（越過陣前自家人、落到後頭敵陣）；貼身近戰反使不上 |
| 盾兵 | 兵／卒 | 舉盾推進、只進不退 → 一步向前；**過河後可左右挪**（結陣靠攏、聚盾合圍） |

> 吃子 → 改稱**「陣亡」**：一詞之差，把抽象博弈變成帶死傷的戰場，殺伐感、代入感全出。
> ※ 參軍原擬名「中軍校尉」，因「中軍校尉」為曹魏才設之官名、188年偏晚，
> 　 改為「執掌中軍號令、調度諸營」，只取職能、不掛具體官名，避開年代風險。

## 長線功能（伏筆，不只是玩具）
1. **餌**：勾朱桓（好勝武膽小孩）之物——見 LuYi.md, Reading People。
   好勝少年輸棋不肯走、只會賴著要贏回，傲反成拴住他、令他一來再來的繩。
2. **練兵場**：日後藉此反覆推演攻守，不著痕跡地訓練一批未來武將的軍事直覺。
3. **人才檔案**：各人怎麼下（朱桓猛攻？顧雍穩守？），即其用兵性格，
   是陸議日後識人用人的底牌。

> 一副「演兵」＝餌＋練兵場＋人才檔案。

## 登場分段
