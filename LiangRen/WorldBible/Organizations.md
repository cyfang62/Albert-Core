# Purpose

本文件定義《良人》所有重要組織、家族與勢力。

目的不是介紹三國歷史。

而是建立小說中各勢力之間的關係與定位。

所有角色皆應隸屬於至少一個組織或勢力。

Organizations 為《良人》唯一的勢力設定基準。

---

# Organization Types

目前分為：

* 家族（Family）
* 政權（Government）
* 軍事勢力（Military）
* 民間組織（Organization）

# Organization Principles

所有組織設定應遵守：

1. 同一角色可隸屬多個身分（例如家族與朝廷官職）。
2. 家族不等於政權。
3. 地方勢力不等於中央朝廷。
4. 組織關係應符合故事時間點。
