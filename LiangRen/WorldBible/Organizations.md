# Purpose

本文件定義《良人》所有重要組織、家族與勢力。

目的不是介紹三國歷史。

而是建立小說中各勢力之間的關係與定位。

所有角色皆應隸屬於至少一個組織或勢力。

Organizations 為《良人》唯一的勢力設定基準。

# 吳郡四姓（顧、陸、朱、張）

Type

Local Gentry Network（地方世族網絡）

Location

揚州・吳郡（吳縣）

Status

Active

Description

吳郡本地世族的合稱，四家世居吳郡吳縣，彼此聯姻、互通聲氣，

構成江東地方的世族網絡。史載吳郡以「顧、陸、朱、張」為四姓（見《吳錄》）。

於本作的作用：

陸議在第008節受挫後轉向——「直往上（廬江那一層）搆不著，

先在吳郡世家圈把自己做大」。第009節起，四姓中三家逐一登門，

即為陸議織「世家網」的起點。此四姓網絡，是他橫向壯大的舞台。

四姓分述（188 年）

* **顧氏**——本作登場：顧雍（字元歎，168生，蔡邕高徒、日後東吳丞相；陸議姑丈）。
  見 Characters/Gu/GuYong.md。味：治。第009節首位登門。
* **陸氏**——即主角家族（詳見下方獨立條目）。
* **朱氏**——本作登場：朱桓（字休穆，177生，日後東吳名將；吳郡吳縣土著朱氏）。
  見 Characters/Zhu/ZhuHuan.md。味：武。第009節隨父來訪、被演兵勾住。
  **注意：朱桓（四姓土著朱）≠ 朱然（本名施然、丹陽朱治養子），非同一家，勿混。**
* **張氏**——本作登場：張允（張溫之父，輕財重士、俠名青年）。
  見 Characters/Zhang/ZhangYun.md。味：義／暖。第009節登門，惜才至動收義子之心（伏筆）。
  下一代：張溫（193生），日後東吳選曹尚書；「你有弟弟囉」伏筆之對象。

> 史實界線（188 年）：四姓下一代多未到位——張溫（193生）尚未出生；
> 朱桓僅11歲；顧氏可用者為20歲的顧雍。朱然（施然）此時6歲、在丹陽、未過繼，
> 且不屬四姓之朱，登場另計（約195後）。撰寫涉及四姓下一代時須對照生年，
> 勿使未出生／未到位者提前登場。

# 陸氏

Type

Family

Location

揚州・吳郡（吳縣）

Status

Active

Description

江東名門望族。

以儒學、仕宦與家族聲望聞名。

故事初期，

小說主要舞台即圍繞吳郡陸氏這一房展開。

Current Members（188 年）

登場：

* 陸議（主角，5 歲）
* 姨母（生母之姊妹，吳郡撫養者）
* 福伯（老僕）
* 陳管事（帳房管事）

提及、未登場：

* 陸康（從祖父，廬江太守，遠在廬江）
* 陸駿（陸議之父，九江都尉，已早逝）

背景、已逝：

* 陸紆（陸議祖父，陸康之兄，城門校尉）
* 陸議生母（原陸夫人）

> 註：陸議屬陸紆一房（長房）；陸康為陸紆之弟。
> 陸康雖為從祖父，於 188 年是支撐全族、官位最顯的長輩。

# 東漢朝廷

Type

Government

Capital

洛陽（188 年，故事開始時）

Emperor

漢靈帝（在位至 189 年）

Status

Active

Description

名義與實質仍存的中央政權。

188 年（中平五年），

朝廷採劉焉之議，

確立「州牧」制度，

賦予州級長官實權——

此舉日後加速地方割據。

故事開場時，

天下尚未全面分裂，

但崩解的種子已經埋下。

> 大規模諸侯割據始於 189 年（董卓亂政）之後，
> 故 188 年的朝廷仍相對完整。

# Organization Relationship（188 年）

```text
東漢朝廷（漢靈帝，都洛陽）
│
└── 地方
     │
     ├── 揚州・吳郡 ── 吳郡四姓：顧、陸、朱、張（士族網絡，非政權）
     │                 （陸氏為主角家；顧雍／朱桓／張允見各角色檔）
     │
     ├── 揚州・廬江 ── 陸康（廬江太守）
     │
     └── 各地將領、太守（孫堅等，仍奉漢室）
```

陸氏屬江東士族，

但並非地方政權本身。

小說中需區分：

家族、

地方官職、

中央朝廷，

以及尚未成形的孫氏勢力。

# Organization Principles

所有組織設定應遵守：

1. 同一角色可隸屬多個身分（例如家族與朝廷官職）。
2. 家族不等於政權。
3. 地方勢力不等於中央朝廷。
4. 組織關係應符合故事時間點（188 年）。
5. 涉及首都、勢力歸屬時，需對照年代（見 Capital Note）。
