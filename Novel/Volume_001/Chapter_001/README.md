# Story Summary

故事開始於：

中平五年（西元 188 年）。

現代人陸博彥於手術中失去意識，

醒來成為六歲的陸議（字伯言，後世之陸遜）。

在接受「回不去」的現實後，

他決定不白來這一趟。

隨著對陸府現況的了解，

他逐漸發現：

* 父母俱亡，這一房只剩自己，由姨母撫養，處境弱勢。
* 族中已有人藉「代為管家」試探、伸手。
* 從祖父陸康遠在廬江任太守，是支撐全族、卻將面對袁術的人。

透過查閱帳冊，

陸議整理出陸家各莊田「不斷減戶」的規律，

並追出根因並非管理問題，

而是歷年疫病。

他的應對，不是發明什麼新東西——

皂角莊上本就有、人人在用；

他真正做的，是**立規矩**：

讓眾人養成洗手的習慣，並將病人集中隔離照護。

一季之後，帳面證明這套規矩有效：

他莊照舊死人，唯陸家莊死者寥寥、人未減、租未缺。

第一章的核心，

不是改變歷史，

而是讓陸議下定決心、並踏出第一步：

先在這個時代站穩，

再設法少死一些人。
