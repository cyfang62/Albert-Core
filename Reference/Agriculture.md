# Agricultural Decision

若主角希望改善農業，

需評估：

* 是否具備知識。
* 是否取得土地。
* 是否有人力。
* 是否能取得工具。
* 是否符合季節。
* 是否符合當地自然環境。

知識本身，

不等於立即提升產量。

# 拓墾良田（產權不動·勘測服務·分帳誘導）研究（§6起）

Topic

郡府主導的荒地開發：不奪產權，以服務與分帳誘導世家自願開墾

Source

史上屯田/勸農概念 ＋ 前世「以誘因對齊各方利益」的機制設計

Summary

**★總綱：驅動的是「人（勞力）」不是地——有人有地就啃、勞力不閒置。**

* **產權鐵律**：無土地易主。世家的地還是世家的、官府的地還是官府的。分的是產出（糧）、不是地。
* **分帳＝三方（農戶／出地方／出人方），數字即糧數**。產權不動、分的是產出（糧）。
  農戶（下田流汗的）**固定拿50**＝不剝削勞動力；出人方（調佃戶/難民做工的世家/官府）**固定拿10**＝派人的理由；出地方（地主）**隨地遞減**：甲40/乙30/丙20/丁10。三者相加＝產值(甲100/乙90/丙80/丁70)。
* **三方共贏**：出人方不挑地(固定10)→爛地也肯派人墾；農戶不挑地(固定50)→勞力可自由調度；出地方按地好壞→好地多拿、爛地本撂著是0抽10白撿。沒一方卡住、地一塊塊被啃滿。
* **官府賺稅、不搶糧**：那50真進農戶口袋。官府圖「地墾出→年年課稅」；每8人1個下田必納稅（接糧食模型人口÷8），人口漲→稅基漲。
* **勞力引擎＝減病＋難民**：減病掃亡（§6）人口漸增；更大宗是收難民（編入官民安置）。難民沒地、需活路→正是官府拿去墾地的人。閉環：減病＋收難民→人多→要有地種→先墾官地再墾世家好地→全郡地力啃滿→糧多→養兵養民。
* **地籍＝底層基礎設施**：拓墾須先踏勘、畫甲乙丙丁、記誰的地/墾沒墾→官府得全郡土地清冊。地籍→可**推算糧冊**（不必等上報即估全郡糧產）、**報不了假**（墾沒墾繩尺量得出，瞞報對不上地籍）、**往後徵糧/安置/戰時清點的地基**。★陸議真正圖的是這套「能一直算下去的帳」，非一季之糧。
* **陸家帶頭**：陸家先把自家甲等好地交官府的人墾、**按三方分帳（農戶50／陸家40／官府10）**做示範（「若連陸家都捨不得，又怎能勸旁人？」），世家眼熱跟進、官府的人就有好地可啃。〔2026-07 校正：原寫「按甲4/6分帳」＝已作廢的兩方版。〕

Historical Limitation

須符合東漢農業水準（工具、勞力、季節）；開墾見效需時間，非即時。入夏時春耕已過、農閒操演需待夏收後。

Novel Usage

§6結尾啟動（陸家帶頭·陽謀切片）；**三方分帳＋地籍**為§7正片。研究性細節此處，正文只挑勾人切片。
